# Tools and Armor

Tools are Pickaxe, Axe, Shovel, Hoe
Weapons are Sword, Axe, Spear (TDB mace, trident, bow)
Armor are helmet, chestplate, leggings, boots

# Materials

Standard Tools & Weapons:
- Wood
- Stone
- Copper
- Gold
- Iron
- Diamond
- Netherite

Standard Armor:
- Leather
- Chain(mail)

# "Parts"

Each item has only 1 "part", the main tool material.

# Upgrading Tools

Each tool and weapon can be upgraded using an upgrade template and one item of target material in a smithing table. An upgrade template costsd 8 material and 1 paper (except for netherite). The netherite upgrade template recipes are changed to cost 1 netherite and 1 paper (or can be found).

Tools & Weapons upgrade order: 
wood -> stone  -> iron -> diamond -> netherite
        copper -> iron
        gold   -> iron

Armor upgrade order: 
leather -> copper -> iron -> diamond -> netherite
           chain  -> iron
           gold   -> iron

# Fixing Tools

The anvil can be used to restore the default amount of durability (~25%). Also removes the anvil work penalty for all types of anvil work.
